# WeLearn

WeLearn is my personal repository where I store the Data Structures and Algorithms (DSA) and LeetCode problems I solve using TypeScript. This repository is purely for learning purposes, and I aim to improve my problem-solving skills, algorithmic thinking, and understanding of DSA concepts as I progress.

## Structure

Each folder in this repository contains:

1. **A README file**: Explains the problem, my approach, the solution, and its time and space complexity.
2. **A TypeScript file**: Contains the TypeScript implementation of the solution.
